# CCXfer

## Description

CCXfer is a command-line tool for collecting, versioning, and restoring Claude Code personalizations across machines. It captures your CLAUDE.md files (both project-level and global), aliases, Claude configurations, plugins, commands, agents, and skills into a portable repository structure. A companion restore script deploys those settings onto a new machine, using Claude itself to evaluate the destination environment and adapt paths, shell configs, and token requirements accordingly.
